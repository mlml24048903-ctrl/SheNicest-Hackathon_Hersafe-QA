# 她测 HerSafe QA · 使用文档

> 面向产品经理、设计师和测试人员的**女性友好与安全情境审查工具**。
> 她测不是通用 UI 可用性工具。截图和图层用于定位证据，产品最终审查的是女性在隐私、控制、位置、骚扰与求助情境中的安全。
> 本项目不构成法律意见、安全认证，也不替代真实女性用户研究和专业安全评审。

产品文档：[`docs/PRD.md`](PRD.md)（需求基线）· [`docs/ROADMAP.md`](ROADMAP.md)（开发路线）

## 1. 环境要求

| 依赖 | 版本要求 | 说明 |
|------|---------|------|
| Node.js | ≥ 20 | |
| pnpm | ≥ 10 | 包管理器（构建脚本放行配置在 `pnpm-workspace.yaml`） |
| Chromium（可选） | — | 仅「网站抓取」与「PDF 导出」需要；`pnpm install` 的 postinstall 自动安装，缺失时手动执行 `pnpm exec playwright install chromium` |
| StepFun API Key（分析必需） | — | 初步分析、待办对话和高风险复核使用（阶跃星辰，OpenAI 兼容接口） |

## 2. 安装与启动

```bash
# 1) 安装依赖（原生构建脚本已在 pnpm-workspace.yaml 的 allowBuilds 放行；
#    postinstall 自动安装 Chromium 并生成 Prisma 客户端）
pnpm install

# 2) 初始化 SQLite 数据库
pnpm db:push

# 3)（可选）生成演示项目：覆盖 截图→图层→待办→对话→确认写入→报告 完整动线
pnpm db:seed

# 4) 启动开发服务器
pnpm dev              # → http://localhost:3000
```

**真实模型接入**：复制 `.env.example` 为 `.env`，填入 `STEPFUN_API_KEY`（阶跃星辰 StepFun，OpenAI 兼容接口）。用户项目不提供离线模拟分析；缺少 Key 时，上传和静态解析仍可使用，但进入模型分析会明确提示配置模型密钥。

## 3. 核心使用流程

整体动线：**创建项目 → 上传材料 → 图层审查 → AI 初始分析 → 待办对话补充事实 → 生成/导出报告**。

### 3.1 创建审查项目（首页 `/`）

1. 左侧「创建审查项目」卡片：填写**项目名称**（必填）与**简要描述**（可选），点击「创建项目」。
2. 创建成功后项目出现在右侧「我的项目」列表，点击卡片进入审查台。
3. 项目状态标识：`待上传材料`（灰）→ `初始分析中`（蓝）→ `已完成初始分析`（绿）。

### 3.2 上传材料（审查台 `/projects/[id]`）

材料分两级（PRD F1.3 优先级引导），均为虚线拖放框，点击选择：

| 分组 | 类型 | 限制 | 说明 |
|------|------|------|------|
| **首选** | 网站 URL | 每项目限 1 个 | 公开页面只读抓取；不执行点击、支付、发布等高影响动作 |
| **首选** | 产品截图 | PNG/JPEG ≤12 张 | 图层检测与证据定位的主要载体 |
| **补充** | PDF | ≤20 页 / 50MB | 不便提供网站/截图时的替代材料 |
| **补充** | DOCX / MD / TXT | ≤5MB | 产品说明、需求文档等 |

- **至少提供一种可解析材料**即可工作；截图与 URL 组合效果最佳。
- 重复截图自动按 pHash 去重（上传成功提示会显示「去重 n 张」）。
- 上传结果通过页面顶部彩色 Banner 反馈（绿=成功 / 红=失败 / 白底琥珀左条=重要提示）。

### 3.3 图层审查台（左侧画布）

候选图层由**像素边缘检测 + 连通区域分析**确定性计算（Sobel/CCL，零模型费用），
漏识别可手工框选补位：

| 操作 | 方式 |
|------|------|
| 切换模式 | 「标注模式 / 风险图层模式」分段切换 |
| 手工框选 | 点「手工框选」→ 在截图上拖拽绘制 |
| 修改类型/关联规则 | 选中图层后在下方操作面板修改 |
| 删除图层 | 操作面板「删除图层」按钮（红色，无按压缩放反馈以示慎重） |
| 五选项确认 | 「确认现状（五选一）」胶囊：现状不存在 / 有设计无截图 / 无法验证 / 其他 / 已有保护 |
| 补充截图 | 选「有设计无截图」后上传补充截图 → 材料进入【待复核】，不自动判定风险消失 |

图层四态颜色编码（图例见画布工具栏右侧）：

| 状态 | 颜色 | 含义 |
|------|------|------|
| 已确认风险 | 红 | 人工确认存在风险 |
| 需补充证据 | 琥珀 | 有风险假设，待补充材料验证 |
| 已有保护 | 绿 | 该情境已有保护设计 |
| 未确认 | 灰（虚线框） | 候选图层尚未人工确认 |

### 3.4 触发 AI 初始分析

材料就绪后点右上角「触发 AI 初始分析」：

- 生成 **3–5 个高价值待办** + **初始风险假设**；
- 分析中按钮显示旋转图标与「分析中…」，完成后按钮自动禁用（每项目仅需一次）。

### 3.5 待办清单与对话（右侧 Tab「待办清单」）

- 待办按优先度徽标展示（高=红 / 中=琥珀 / 低=蓝）+ 状态徽标（7 种状态）。
- 点开待办进入**对话视图**：AI 会追问产品实际行为，直接输入补充事实即可。
- **对话附件**（输入区回形针按钮）：可直接上传补充材料随消息发送——
  支持图片（jpg/png/webp）、PDF、文档（docx/md/txt），**每条消息最多 4 个文件、至多 1 份 PDF**；
  附件走完整材料解析管线入库（进入项目证据包、参与 pHash 去重、计入项目 12 张截图额度）；
  图片会作为多模态输入让 AI 直接「看图」分析，PDF/文档解析文本后摘录注入对话上下文；
  重复上传同一张图会命中去重（提示「已去重」，AI 仍可见原图）；纯附件消息（不输入文字）也可发送。
- AI 产出「拟写入证据摘要」proposal 后，底部出现琥珀确认区：
  点击「确认写入 EvidenceUpdate」完成**事务写入**——仅更新关联风险，其他结论不动；
  涉及跨风险关联时自动新建关联待办。
- `needs_manual` 状态的待办显示红色提示区，需人工处理。

### 3.6 风险报告（`/projects/[id]/report`）

- **总览**：四类结论统计卡（已确认风险 / 待验证风险 / 需求缺口 / 已有保护，图标格渐变底），窄屏自动折 2 列。
- **四组结论**：每条 finding 卡带左侧语义渐变色条（红/琥珀/蓝/绿，扫读锚点），行首类型图标 +
  类型/严重度徽标、维度/规则 chip、材料来源、研究依据、
  观察事实 / **用户确认事实**（绿）/ 模型推断 / 修改建议（蓝），以及 **Given-When-Then 测试用例**（品牌虚线域 + ▸ 锚点，一键复制）。
- **导出**：右上角「导出 Markdown / 导出 PDF」。
- 页脚免责声明；模型未配置或调用记录不可核对时显示明确提示，不生成替代结论。

## 4. 界面功能说明

- **极光氛围层**：全站 fixed 底层的低饱和粉紫极光渐变（rose→lilac→peach，不随滚动、不拦截事件）；
  辅助色仅用于背景/描边/大标题渐变端点，正文文字保持中性灰——「降噪不过度告警」的底色语言。
- **全局品牌头**：sticky 玻璃拟态顶栏（滚动不消失，可透出极光微染），点击站名回首页；右上角「内部演示版」幽灵胶囊角标。
- **开场声明**：首页顶部白底琥珀左条降噪横幅（PRD §1.5 合规要求，常驻展示）。
- **交互覆盖率进度条**：证据包 Tab 内，展示 `covered / (covered + uncovered)` 百分比与逐项计数；计算中显示流动条纹。
- **反馈规范**：操作反馈统一为页面内 Banner（绿=成功 / 红=失败 / 蓝=信息 / 白底左条=警示），可传入关闭按钮。
- **动效纪律**：反馈类 ≤250ms（按压缩放、复制反馈、确认渐入）；环境/信息型 ≥2.4s（骨架屏扫光、分析中呼吸点、覆盖率流动条纹、极光漂移）；
  hover 专属：卡片渐变描边、主按钮光泽扫过、图层框轻微加亮。系统开启「减弱动效」时全部关停（含极光伪层摘除）。

## 5. 配置说明（.env）

复制 `.env.example` 为 `.env` 后按需填写：

| 变量 | 默认值 | 说明 |
|------|--------|------|
| `DATABASE_URL` | `file:./dev.db` | SQLite 数据库文件位置 |
| `STEPFUN_API_KEY` | 空 | 阶跃星辰 StepFun API Key；用户项目进行模型分析时必填 |
| `STEP_BASE_URL` | `https://api.stepfun.com/step_plan/v1` | OpenAI 兼容接口地址（pro plan 专属网关） |
| `STEP_MODEL` | `step-3.7-flash` | 多模态调用模型（截图分析） |
| `STEP_TEXT_MODEL` | `step-3.5-flash-2603` | 纯文本调用模型（待办追问/复核） |
| `MAX_IMAGES` | 12 | 单项目截图上限 |
| `MAX_PDF_PAGES` | 20 | PDF 页数上限 |
| `MAX_PDF_MB` | 50 | PDF 大小上限 |
| `MAX_DOC_MB` | 5 | 文档大小上限 |
| `MAX_IMG_MB` | 10 | 单张截图大小上限 |

## 7. 常见问题（FAQ）

**Q：启动时报「Port 3000 is in use」？**
A：3000 端口被其他进程占用（常见于上一会话遗留的 dev server）。Next 会自动换端口（如 3001）；
如需固定端口，先结束占用进程再启动。

**Q：没有配置 `STEPFUN_API_KEY` 时会发生什么？**
A：上传、代码静态解析和规则库仍可使用，但初步分析、待办对话与高风险复核不会生成模拟结论。系统会提示配置真实模型密钥后重试。

**Q：删除项目会发生什么？**
A：联动删除该项目全部原始文件、解析产物与报告（首页知情同意条款中已注明）。

**Q：图层漏识别了怎么办？**
A：Sobel/CCL 为确定性检测，漏识别属正常边界；点「手工框选」拖拽补位即可，
人工框选的图层同样参与后续五选项确认与风险流程。

**Q：可以审查移动 App 吗？**
A：当前 MVP 面向网页产品 URL 与截图；App 情境直接用截图作为材料审查即可（演示项目即 App 截图场景）。
